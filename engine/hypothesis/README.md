# Hypothesis-Driven Scientific Discovery Pipeline

**Core thesis:** AI-READI is a population-scale experiment in synchronized human physiology. The primary object is not a feature table; it is a coupled dynamical system observed for ~10 days across metabolic, autonomic, behavioral, sleep, and environmental channels.

## System Architecture

```
Proposer Agent  -->  Critic Agent  -->  Hypothesis Workspace  -->  Executor Agent  -->  Verifier Agent
  (literature,       (feasibility,      (JSON-backed,              (runs analysis,      (statistical
   mechanisms,        confounders,        prioritized queue)         code generation)      rigor, FDR,
   predictions)       negative ctrls)                                                     effect sizes)
```

Implemented locally as Python agents that reuse the repository's agent
infrastructure and write structured state to JSON. Future integrations may
replace the local LLM/backend plumbing, but the hypothesis schema and workspace
state machine are the durable interface.

## Hypothesis Lifecycle

```
proposed -> critiqued -> validated -> queued -> executing -> completed -> verified -> supported/refuted/inconclusive
                      -> rejected
```

## Directory Structure

```
hypothesis_driven/
├── schemas.py              # Pydantic-style dataclasses for structured output

```

## Critical Constraints

1. **Garmin HR is the binding constraint**: averaged at 1-5min, not beat-to-beat. Limits 8/18 hypotheses.
2. **Medications redacted**: cannot distinguish coupling-severity gradient from medication-regimen gradient.
3. **No meal timing**: cannot attribute glucose excursions to meals vs spontaneous.
4. **Cross-sectional**: temporal precedence within 10 days does not establish causality.
5. **10-day window**: limits multi-day frequency estimates and within-person repeated measures.

## Hypothesis Quality Requirements

Every hypothesis MUST specify:
- Specific expected **direction** (not "differs")
- Expected **lag or timescale**
- **Refutation criterion** (what kills it)
- **Negative controls**
- **Confounders** to adjust for
- What part of AI-READI **uniquely enables** this test

## Usage

```python
from hypothesis_driven import HypothesisWorkspace

ws = HypothesisWorkspace()
print(ws.summary())

# Get next hypothesis to execute
h = ws.next_to_execute()
print(h.full_report())

# After running analysis, record results
from hypothesis_driven.schemas import HypothesisResult
ws.set_results(h.id, HypothesisResult(
    method_used="wavelet_coherence",
    sample_size=1939,
    primary_metric="Cohen_d_1_4h_band",
    primary_value=0.72,
    ...
))
```
