# Split Assignments

The AI-READI metadata provides `recommended_split` in `data/participants.tsv`.
The project keeps that column unchanged.

For sensitivity analyses, use deterministic local split columns generated by:

```bash
python -m scripts.splits
```

This writes:

- `results/features/split_assignments.parquet`
- `results/features/split_balance_report.csv`
- `results/features/split_balance_summary.json`

Current alternate split:

- `balanced_split_v1`
- Stratification variables: `clinical_site`, `study_group`, coarse age bin
- Seed: `20260430`
- Target fractions: 70% train, 15% validation, 15% test

Use a split with model scripts:

```bash
python -m scripts.aging_clocks --split-column balanced_split_v1
python -m scripts.unified_clock --split-column balanced_split_v1
python -m scripts.retinal_age --from-embeddings --split-column balanced_split_v1
python -m scripts.cardiac_age --from-embeddings --split-column balanced_split_v1
```

Non-default split runs write suffixed artifacts, for example
`clock_performance__balanced_split_v1.csv`, so they do not overwrite the
default `recommended_split` outputs.

Outlier handling is separate from split selection. The all-feature multimodal
clock does not clip feature values by default. `--clip-outliers` enables
train-only winsorization and should be reported as a sensitivity analysis.
