# Documentation Map

`docs/CURRENT_STATUS.md` is the first file to read. The rest of this directory
is organized by purpose so dated notes do not look like current implementation
truth.

## Current

- `CURRENT_STATUS.md`: source-of-truth project state, guardrails, and recent
  high-risk fixes.

## Reference

- `reference/DATA.md`: dataset schema and modality reference.
- `reference/LOADING.md`: loader and feature-matrix API reference.
- `reference/DERIVED_FEATURES.md`: derived-feature formulas and caveats.
- `reference/SPLITS.md`: provided and project-local train/validation/test split
  columns, balance diagnostics, and model-script usage.

## Design

These files explain project direction or architecture. Some are historical
roadmaps and should be read with `CURRENT_STATUS.md`.

- `design/STUDY_DESIGN_AGING_CLOCKS.md`
- `design/BRAINSTORM_NETWORK_PHYSIOLOGY.md`
- `design/AGENT_SYSTEM_BRAINSTORM.md`
- `design/HYPOTHESIS_DISCOVERY_SYSTEM.md`
- `design/HYPOTHESIS_FIRST_AGENTIC_IMPLEMENTATION.md`
- `design/IMPLEMENTATION_ROADMAP.md`
- `design/INFRASTRUCTURE_PLAN.md`

## Decks And Prompts

- `decks/`: markdown deck sources and local generated deck assets.
  - `decks/progress_update_20260424/`: April 24 progress-update slideshow
    workspace, including source markdown, build script, assets, and notes.
- `prompts/`: image and visual-generation prompts.

## Archive

`archive/` holds dated audits and project snapshots that should not be used as
current status.
