# AI-READI progress update slideshow

Generated local deck package for the AI-READI multimodal foundation-model and agent-system progress update.

## Files

- `progress_update_deck.html`: browser slideshow with keyboard navigation.
- `progress_update_deck.md`: Marp-style Markdown source for further editing.
- `speaker_notes.md`: slide-by-slide presenter notes.
- `assets/`: deterministic SVG figures used by the deck.
- `sources.json`: docs and results referenced while generating the deck.
- `image_prompts.md`: prompts for the generated raster visuals.
- `build_deck.py`: local generator script.

## How to view

Open `progress_update_deck.html` in a browser. Use left/right arrows or the on-screen controls.

The current deck has 16 slides and emphasizes:

- AI-READI as a 2,280-participant, 9-modality synchronized physiology substrate.
- The 10-day concurrent wearable + CGM + environment window.
- The four-layer architecture: data infrastructure, foundation-model perception, multi-agent reasoning, and Longevity OS/N-of-1 bridge.
- Concrete roles for each modality and reasoning agent.
- Current aging-clock and subtype results from `results/`.
- Generated text-free visuals for the hero, agent layer, and N-of-1 loop.
- Future plans for N-of-1 trial suggestions and TextGrad-like test-time improvement.
